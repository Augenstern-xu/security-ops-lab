# Security Ops Lab

自建四节点实验集群上的安全运维实践：**主机加固 → 渗透验证 → 基线审计**，以及日志、监控与备份。

## 这个仓库是什么

不是教程，也不是工具集，而是我在一套自建环境里把安全运维的完整流程跑了一遍之后留下的**可验证记录**：判据怎么冻结、证据怎么留、整改怎么复验、失败怎么回滚。

所有主机名、IP、账号都已脱敏为占位符（`node-1` ～ `node-4`、`192.0.2.x`），仓库中不含任何口令、密钥、指纹或真实拓扑。

## 项目亮点

- **证据驱动**：每条结论都带命令、原始输出、带时区的时间和精确定位；没有"基本满足"。
- **可复现**：4 个只读、可重跑的基线采集/复验脚本，任意时点重跑得到同一口径。
- **会回滚**：一次错误判据导致日志链路中断 4 分钟，定位、回滚、修订判据，全过程留痕。
- **配置可追溯**：31 个受管配置文件入 git，三道脱敏闸，钩子实测拦下一次明文密码。
